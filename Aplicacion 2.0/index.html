Scanner interactivo multi-objeto

Esta demo activa tu cámara y ejecuta detección en vivo con OpenCV.js usando el detector HOG de peatones (biblioteca pre-entrenada de OpenCV) más contornos para objetos generales, mostrando etiqueta y confianza al estilo Ultralytics. Envía métricas anónimas a un backend serverless en Vercel como práctica de Machine Learning / Visión por Computador.
