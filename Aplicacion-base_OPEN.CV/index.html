¿Qué hace esta aplicación?

Esta aplicación web utiliza OpenCV.js para realizar operaciones aritméticas y lógicas entre dos imágenes directamente en el navegador.

El objetivo es mostrar cómo OpenCV puede combinar imágenes píxel a píxel usando técnicas comunes en visión por computadora, como suma, resta, operaciones bitwise y mezclas ponderadas.

Este tipo de procesamiento se utiliza en áreas como detección de movimiento, análisis de imágenes, efectos visuales y preprocesamiento para inteligencia artificial.
