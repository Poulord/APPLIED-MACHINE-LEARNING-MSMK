Operaciones aritméticas con imágenes

Suma, resta, operaciones bitwise y blending. Usa dos imágenes y explora las combinaciones más comunes del tutorial de OpenCV.js.

¿Qué es esta aplicación?

Esta demo usa OpenCV.js para mostrar cómo combinar dos imágenes usando operaciones aritméticas y lógicas. Es útil para entender conceptos básicos de visión por computador como mezcla, resta, detección de cambios y uso de máscaras.

Carga dos imágenes, elige un filtro y observa el resultado en tiempo real. Si las imágenes no tienen el mismo tamaño, puedes ajustar automáticamente con la opción de auto-resize.

¿Qué hace cada filtro?

Estas operaciones combinan dos imágenes (A y B) o aplican un efecto directo sobre una sola. Úsalas como guía para elegir el filtro adecuado según tu objetivo.

  • add (A + B): suma píxeles para aumentar brillo o fusionar contenido.
  • subtract (A - B): resta píxeles para resaltar diferencias o oscurecer zonas.
  • absdiff |A - B|: diferencia absoluta para detectar cambios entre imágenes.
  • bitwise AND: conserva solo las áreas comunes (ideal para aplicar máscaras).
  • bitwise OR: combina ambas imágenes, mostrando cualquier píxel activo.
  • bitwise XOR: muestra diferencias exclusivas entre A y B.
  • bitwise NOT (A): invierte los colores de la imagen A.
  • blend (addWeighted): mezcla controlada con alpha para superponer imágenes.
